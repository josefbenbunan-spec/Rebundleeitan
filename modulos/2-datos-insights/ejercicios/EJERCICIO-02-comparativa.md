# Ejercicio 2: Análisis Comparativo

## Tiempo: 7 minutos

## Objetivo
Comparar datos entre diferentes períodos o categorías.

## Instrucciones para el estudiante

**IMPORTANTE para Claude:** Presentar los pasos UNO A UNO. No mostrar todos los pasos de golpe.

### El reto: Encontrar tendencias

Los datos solos no dicen mucho.
Las COMPARACIONES revelan tendencias.

### Paso 1: Elige qué comparar (1 min)

Opciones:
- Este año vs año anterior
- Cliente A vs Cliente B
- Primer semestre vs segundo semestre
- Correos recibidos vs enviados

Mi comparación: _______________________

### Paso 2: Pide la comparativa (3 min)

Escribe a Claude:
```
Compara [OPCIÓN 1] vs [OPCIÓN 2]:
- ¿Cuál tiene más actividad?
- ¿Cuál genera más valor?
- ¿Hay tendencias que debería notar?
- ¿Qué conclusiones puedo sacar?
```

**Ejemplo:**
```
Compara mi relación con Alpha vs mi relación con Beta:
- ¿Cuál tiene más actividad?
- ¿Cuál genera más valor?
- ¿Hay tendencias que debería notar?
- ¿Qué conclusiones puedo sacar?
```

### Paso 3: Lee los insights (2 min)

Claude te dará algo como:
```
COMPARATIVA: Alpha vs Beta

| Métrica | Alpha | Beta | Ganador |
|---------|-------|------|---------|
| Correos | 45 | 12 | Alpha |
| Facturas | €15,000 | €8,000 | Alpha |
| Reuniones | 8 | 3 | Alpha |
| Última comunicación | Ayer | Hace 3 meses | Alpha |

CONCLUSIONES:
1. Alpha es claramente tu cliente principal (65% más actividad)
2. Beta está decayendo - sin contacto en 3 meses
3. Recomendación: Reactivar Beta o buscar nuevo cliente
```

### Paso 4 (opcional): Una pregunta más

Si te sobra tiempo, pregúntale algo estratégico:

```
"¿Qué pasaría si pierdo a Alpha? ¿Tengo muy concentrado el riesgo?"
```
