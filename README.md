Kit personal de **Eitan** para el curso presencial de Claude Code (Rebundle, 8 h).

## Ejecutarlo online (sin instalar nada)

1. Necesitas una cuenta de **Claude Pro** (el curso incluye 3 meses).
2. Entra en **https://claude.ai/code** e inicia sesión.
3. La primera vez, conecta tu cuenta de **GitHub** cuando te lo pida.
4. Crea una sesión nueva sobre este repositorio:
   **`betobetico/rebundle-eitan`** (rama `main`).
5. Cuando se abra la sesión, escribe:

   ```
   /empezar
   ```

Claude te guía a partir de ahí. Todo corre en la nube, en tu navegador.
