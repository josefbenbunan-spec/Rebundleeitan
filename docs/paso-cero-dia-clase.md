# PASO CERO - Hoja para tu Mesa

> Haz esto al sentarte. Son 5 pasos de 1 minuto cada uno.

---

## 1. Abre la Terminal

**Mac:** Pulsa **Cmd + Espacio**, escribe **Terminal**, pulsa **Enter**.

**Windows:** Pulsa la tecla **Windows**, escribe **PowerShell**, pulsa **Enter**.

---

## 2. Comprueba que Claude Code funciona

Escribe esto y pulsa Enter:

```
claude --version
```

Si ves un numero, todo bien. Si da error, **levanta la mano**.

---

## 3. Ve a la carpeta del curso

Escribe esto y pulsa Enter:

```
cd ~/rebundle
```

Si dice "No such file or directory" o "no se encuentra la ruta", **levanta la mano**. El profesor te ayudara.

---

## 4. Arranca Claude Code

Escribe esto y pulsa Enter:

```
claude
```

Espera unos segundos. Veras el cursor de Claude listo para escribir.

---

## 5. Empieza el curso

Escribe:

```
empezar
```

Claude te guiara a partir de aqui.

---

## Si algo no funciona

**Levanta la mano.** El profesor esta para eso.

No intentes solucionarlo solo. Estamos aqui para ayudarte.

---

## Skills utiles durante la clase

| Escribes esto... | ...y pasa esto |

| `Ctrl + C` | Parar lo que este haciendo Claude |
